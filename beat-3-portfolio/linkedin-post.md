Recently, I contributed to the open source CampusOS project by implementing a calendar feature that allows users to update existing events. Before my contribution, CampusOS could create and retrieve calendar events, but users couldn't update existing ones. 

I implemented the update capability as part of my pull request. After I opened the pull request, a CampusOS maintainer reviewed my work and gave me feedback for improving it. 

I updated the implementation based on the maintainer's feedback and tested the changes again. My proposed update would allow CampusOS users to modify an existing calendar event instead of creating a new one when information changes. From this experience, I learned how to work with an existing codebase and respond to real maintainer feedback. Link to PR: https://github.com/NITRR-Official/CampusOS/pull/134
