Recently, I contributed to the open source CampusOS project by implementing a calendar feature that allows users to update existing events. Before my contribution, CampusOS could create and retrieve calendar events, but users couldn't update existing ones. I implemented the update capability and tested it to make sure it worked correctly. After I opened the pull request, a CampusOS maintainer reviewed my work and gave me feedback for improving it. I updated the implementation based on the maintainer's feedback and tested the changes again. After my changes, all 122 calendar tests passed. From this experience, I learned how to work with an existing codebase and respond to real maintainer feedback. Link to PR: https://github.com/NITRR-Official/CampusOS/pull/134
